# 🎬 Netflix Login Project

A Netflix-inspired login page built with **React, Vite, Node.js, and Express**.

The frontend is deployed using **GitHub Pages**.

## 🌐 Live Demo

👉 https://muthu440.github.io/netflix-login-project/

## 📸 Project Preview

A responsive Netflix-style login interface with:

- Email/phone input
- Password input
- Sign In button
- Remember Me option
- Help link
- Sign-up section
- Netflix-inspired dark UI

## 🛠️ Technologies Used

### Frontend
- React
- Vite
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js

### Deployment
- GitHub
- GitHub Actions
- GitHub Pages
